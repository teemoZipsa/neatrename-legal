How can we help with NeatRename?

Always review the live preview before applying a batch rename. If a pattern isn't matching or Apply is blocked, check these practical diagnostic steps.

Install and update

  • Install NeatRename directly from its Microsoft Store page.
  • To check for updates: open Microsoft Store > Library > Get updates.
  • If a newly released version is not offered immediately, it may still be rolling out through Microsoft Store staging.

Common questions

✦ Where are my files processed?

Previews, conflict checks, Apply, and Undo run 100% locally on your PC. NeatRename never uploads your files or directory paths.

✦ Why can't I apply a rename?

Check the issues highlighted in Preview. Apply is blocked by file collisions, duplicate names, invalid regex, or Windows reserved path characters.

✦ Why did a CSV row not apply?

CSV files require an original,new header. A row fails to match if the original name is missing, duplicated, or empty.

✦ Can I undo a rename?

Yes. As long as the renamed files still exist in place, open History and choose the completed batch to revert names immediately.

✦ Can I check privacy details?

Read the privacy policy for comprehensive documentation on file access and local-only storage.

Before reporting a problem

  • If a folder appears empty, verify the file type filter, hidden-file toggle, and subfolder recursion options.
  • If a rename is blocked, use the preview filter or conflict inspector to jump straight to affected rows.
  • If regex replace fails, test pattern syntax with a simple literal replace first.
  • If undo fails, verify that renamed files have not been moved, locked, or deleted by another application.
  • When opening an issue, include your app version, expected outcome, and the exact preview state.

Report a problem

Open a NeatRename support issue on GitHub. Because GitHub issues are public, please redact any sensitive or personal file names and paths before submitting.
