Install and update

  • Install NeatRename from its Microsoft Store page.
  • For updates, open Microsoft Store > Library > Get updates.
  • If a new version is not offered yet, it may still be rolling out to your device or region.

Common questions

Where are my files processed?

Previews, conflict checks, Apply, and Undo run on your PC. NeatRename does not upload your files.

Why can't I apply a rename?

Check the issues shown in Preview. Apply is blocked by conflicts, duplicate or invalid names, an invalid regex pattern, or a path that Windows cannot use.

Why did a CSV row not apply?

A CSV file needs an original,new header. A row will not match if the original name is not in the current batch, appears more than once, or is blank or duplicated in the CSV.

Can I undo a rename?

Yes, if the renamed files are still there and their original paths are free. Open History and select the completed operation to undo it.

Can I check privacy details?

Read the privacy policy for details about file access and data saved on your PC.

Before reporting a problem

  • If a folder shows no files, check the file type filter, hidden-file option, and subfolder option.
  • If a rename is blocked, use the preview filter or issue actions to inspect affected rows.
  • If regex replace fails, check the pattern syntax and try a smaller literal replace first.
  • If undo fails, confirm the renamed files still exist and the original paths are not occupied.
  • Include the app version, what you expected, and what Preview showed.

Report a problem

Open a NeatRename support issue. GitHub issues are public. Remove personal file names, paths, and screenshots before posting.
