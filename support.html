Help for NeatRename users.

NeatRename is distributed through Microsoft Store and runs rename previews, validation, apply operations, and undo history locally on your Windows device.

Open Microsoft Store listing Privacy policy

Install And Update

  • Install NeatRename from the Microsoft Store product page.
  • Use Microsoft Store Library updates to receive the latest available version.
  • If an update is not visible yet, check again after Store rollout reaches your device and region.
  • NeatRename does not require a separate account or cloud service.

Common Questions

Where are my files processed?

Rename previews, CSV mapping, regex replace, conflict checks, apply operations, and undo operations run locally. NeatRename does not upload your files.

Why is Apply disabled?

Apply is blocked when the preview has issues such as duplicate final names, invalid Windows file names, existing-file conflicts, reserved device names, invalid regex patterns, or paths that are too long.

Why did a CSV row not apply?

CSV mapping uses an `original,new` header and matches by loaded original file name. A row may be skipped if the original file is not loaded, appears more than once in the loaded files, is duplicated in the CSV, or has an empty original value.

Can I undo a rename?

NeatRename writes local undo history before applying a rename operation. Undo can restore a completed operation when the files still exist and no conflicting file has taken the original path.

Can I check privacy details?

The privacy policy explains file access, local undo history, presets, CSV mapping, regex replace, and local data controls.

Troubleshooting

  • If a folder shows no files, check the file type filter, hidden-file option, and subfolder option.
  • If a rename is blocked, use the preview filter or issue actions to inspect affected rows.
  • If regex replace fails, check the pattern syntax and try a smaller literal replace first.
  • If undo fails, confirm the renamed files still exist and the original paths are not occupied.
  • If a Store update appears delayed, open Microsoft Store Library and check for app updates.
